# Evaluation Explainer

- Input must be a completed deterministic evaluation result.
- Explain what rule was applied, actual normalized value, expected value, outcome, and evidence location.
- Cite the exact tender clause/page and bidder document page.
- Distinguish AI-extracted, human-verified, rule-computed, and officer-decided information.
- Do not alter pass/fail/status, score, rank, or decision.
- If the result is pending or ambiguous, say what evidence or officer action is needed.
