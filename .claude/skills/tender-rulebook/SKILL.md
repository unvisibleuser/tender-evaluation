# Skill: Tender Rulebook Drafting

Use this skill when asked to inspect a tender pack and create a rulebook.

## Procedure
1. Inventory all tender files and amendments.
2. Determine tender identity, authority, item/work, dates, submission mode, and bid stages.
3. Build document checklist by envelope/cover/channel.
4. Extract eligibility and qualification requirements.
5. Extract technical specification fields with exact values and units.
6. Extract supporting-document checks: holder, issuer, validity, scope, signatures/certification.
7. Extract fee/EMD/security deposit rules and exemption conditions.
8. Extract commercial submission/opening and price evaluation method.
9. Identify clarification and post-deadline rules.
10. Add source references and quote evidence.
11. Flag ambiguities, conflicts, missing thresholds, and inferred interpretations.
12. Validate against `docs/RULEBOOK_SPEC.md`.

Never treat the AI draft as approved policy. Ask an authorized officer to review and publish.
